# QUICK START GUIDE - Install the App

## 📱 For iPhone/iPad Users

1. **Open in Safari** (not Chrome)
2. Go to your website
3. Tap the **Share** button (box with arrow at bottom)
4. Scroll down and tap **"Add to Home Screen"**
5. Enter a name (e.g., "Light Shadows")
6. Tap **"Add"**
7. ✅ App is now on your home screen!

## 🤖 For Android Users

### Option 1: Chrome Browser
1. Open your website in **Chrome**
2. Look for the **Install** popup (or wait 2-3 seconds)
3. Tap **"Install"**
4. App will be added to home screen and app drawer
5. ✅ Done!

### Option 2: Menu Method
1. Open website in **Chrome**
2. Tap **Menu** (3 dots) at top right
3. Tap **"Add to Home Screen"** or **"Install app"**
4. Confirm the name
5. ✅ Done!

## 💻 For Windows/Mac Users

### Chrome or Edge Browser
1. Go to your website
2. Click the **Install** button in address bar (or Menu → Install app)
3. Click **"Install"**
4. App will appear in Start Menu / Applications
5. ✅ Done!

## 🆘 Still Having Issues?

### **Icon Not Showing?**
- Wait 2-3 seconds for install prompt
- Try refreshing the page (Ctrl+R or Cmd+R)
- Try a different browser

### **Won't Install?**
- Make sure you're using a supported browser:
  - iPhone: Safari (not Chrome)
  - Android: Chrome, Firefox, Edge
  - Computer: Chrome, Edge, Safari
- Check internet connection
- Ensure site is on HTTPS

### **App Crashes?**
- Close the app completely
- Reinstall by uninstalling and adding again
- Clear app data and try again
