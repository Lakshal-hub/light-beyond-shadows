## 📊 INSTALLATION BY DEVICE

### 🍎 iPhone/iPad
1. Open in Safari (required)
2. Share → Add to Home Screen
3. See [INSTALL_GUIDE.md](INSTALL_GUIDE.md) for screenshots

### 🤖 Android Phone
1. Open in Chrome/Firefox
2. Install prompt appears
3. Or: Menu → Add to Home Screen
4. See [INSTALL_GUIDE.md](INSTALL_GUIDE.md) for screenshots

### 💻 Windows Computer
1. Open in Chrome or Edge
2. Click install button in address bar
3. Or: Menu → Install app
4. See [INSTALL_GUIDE.md](INSTALL_GUIDE.md) for screenshots

### 🖥️ Mac Computer
1. Open in Safari or Chrome
2. Click install option in menu
3. Or: Safari File → Add to Dock
4. See [INSTALL_GUIDE.md](INSTALL_GUIDE.md) for screenshots
